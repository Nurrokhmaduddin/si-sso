Bantuan Monitor Verifikasi Soal Ujian
Alur Proses
  1. Dosen upload soal ujian.
  2. Admin Prodi menentukan validator.
  3. Validator melakukan verifikasi.
  4. Validator dapat memberi revisi atau approval.
  5. Dosen melakukan upload revisi jika diperlukan.
Status Workflow
  • Belum Upload → soal belum diupload.
  • Sudah Upload → file soal sudah tersedia.
  • Menunggu Verifikasi → menunggu validasi.
  • Revisi → perlu perbaikan dari dosen.
  • Approved → soal telah disetujui.
